# 汽车产业链公司语境

## 适用范围
投递蔚来、理想、小鹏、比亚迪、特斯拉中国、上汽、吉利、长城、博世、大陆、宁德时代等汽车产业链公司时叠加使用。也适用于出行平台（滴滴、T3出行）和自动驾驶公司（Momenta、小马智行等）。

## 汽车产业链简历偏好

### 行业背景
汽车产业正在经历"电动化、智能化、网联化、共享化"四化转型，传统车企在学习互联网的打法，新势力在融合汽车工业和科技创新。简历需要体现你理解这个转型语境。

### 文化关键词
- **用户运营思维**：新势力车企把用户当社区成员而非买家，强调用户生命周期管理
- **软件定义汽车**：OTA升级、智能座舱、自动驾驶等软件能力越来越重要
- **跨界融合**：汽车+互联网+AI的复合背景是稀缺人才
- **长周期项目管理**：汽车项目周期长（6-24个月），需要展示耐心和系统性
- **供应链思维**：理解上下游关系、成本控制、质量管理

### 汽车行业特有术语
- 产品术语：车型（Model）、配置（Trim）、OTA、智能座舱、ADAS、车机系统、HMI
- 销售术语：大定/小定、锁单、交付量、保有客户、置换率、线索转化率
- 用户运营：车主社区、NIO House、试驾转化、保客营销、用户口碑裂变
- 供应链：BOM成本、Tier1/Tier2、SOP（量产启动）、产能爬坡、零部件国产化率
- 新能源：续航里程、补能体系、换电/充电、三电系统（电池/电机/电控）
- 智能化：L2/L3/L4自动驾驶、感知/规划/控制、高精地图、V2X

### 经历包装调整

#### 强调的维度
- **跨界能力**：如果有互联网+汽车的复合经历，重点突出
- **全链路思维**：从洞察→策略→落地→效果的完整链条
- **用户洞察深度**：汽车是高客单价低频决策，用户研究要深
- **项目管理能力**：汽车项目复杂度高，展示你能管理长周期项目
- **数据+业务结合**：不只是做数据，还要懂汽车业务

#### 弱化的维度
- 纯互联网黑话（"私域流量"等在车企语境里不太合适）
- 短期ROI思维（汽车行业看长期价值）
- 过于碎片化的经历（汽车行业看稳定性）

#### 互联网经历 → 汽车产业链的翻译

| 互联网表述 | 汽车语境表述 |
|-----------|-----------|
| DAU/MAU | 活跃车主数/APP活跃率 |
| 用户增长 | 线索获取与转化/保客营销 |
| 内容运营 | 车主社区运营/品牌内容传播 |
| 私域流量 | 车主生态/DTC（Direct to Consumer） |
| A/B测试 | 试点验证/区域试点后全国推广 |
| 快速迭代 | OTA持续优化/敏捷开发 |

### 格式特点
- 新势力车企偏好现代化但不花哨的简历
- 传统车企偏好更保守正式的格式
- 技术背景（编程/数据）单独列出，是明确加分项
- 如果有汽车行业相关经历（哪怕是实习或项目），放在显眼位置

## 特别说明：跨国汽车公司
投递博世中国、大陆中国、特斯拉中国等跨国车企时：
- 简历可以用中英双语或纯英文
- 强调跨文化沟通能力
- 使用全球通用的汽车行业术语（英文）
- 如果有海外经历，适度突出
