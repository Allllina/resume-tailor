# Lens HC — 人力资本 / 人才分析（Human Capital / People Analytics / Org Effectiveness）

**对应简历版本：** HC
**对应 role_family：** `HC_human_capital`
**下位 scenarios：** `human-capital.md` / `people-analytics.md`

---

## 1. What recruiters screen for

招聘人在筛"能不能用数据 + 组织诊断方法，让人才决策与组织决策更可证据化"。底层：**组织 / 人才业务知识 + 分析方法 + 干系人协作（HRBP / line / leadership）+ 把人 / 组织问题翻译成可量化干预**。

---

## 2. Prioritize

- **People analytics 方法** — 人才数据建模 / 留存分析 / 招聘漏斗 / 绩效分析 / 薪酬建模 / 敬业度分析
- **组织诊断** — 组织设计 / span-of-control / 组织效能 / 人员产能（productivity per FTE）/ 重组 / 海外子公司治理
- **薪酬与人才市场** — 薪酬 benchmarking / 人才供需 / 关键岗位市场扫描 / 薪酬结构设计
- **HR 业务伙伴沟通** — 与业务 leader / line manager / HRBP / Total Rewards / Talent Acquisition 的协同
- **政策与合规知识** — 劳动法 / 海外用工合规 / DEI 框架（视市场）
- **数据→决策转化** — 不是 "ran HR report" 而是 "诊断 X 问题导致流失，推动 Y 干预，留存提升 Z"
- **多市场 / 跨文化人才视角** — 跨境用工 / 海外子公司 / 全球人才战略

---

## 3. De-emphasize

- 纯 HR 行政 / 招聘日常运营（除非语境明确加分）
- 不带数据的"组织文化建设"模糊描述
- 招聘量 / 入职量 / 培训次数等过程指标，不绑定业务结果
- 通用 employee experience 软话题没硬证据

| 弱 | assisted (HR) / supported (recruitment) / coordinated (training) | 协助 / 配合 / 跟进（招聘 / 培训）/ 处理 |

## 5. Bullet pattern

**[Action] + [组织 / 人才语境 + scope] + [分析方法] + [洞察] + [人才 / 组织 / 业务结果]**

### NA 示例
> "Diagnosed regrettable attrition drivers across 3 business units (1,200 FTE) using survival analysis and exit-interview text mining, identifying compensation lag and manager-tenure mismatch as primary drivers, advising the leadership team on a $1.5M targeted retention package that reduced 12-month attrition by 18%."

### 内地示例
> "诊断 3 个事业部（1,200 人规模）的关键人才流失驱动因素，结合生存分析与离职访谈文本挖掘，识别薪酬倒挂与直属经理任期错配两大核心驱动，向管理层提出 1.5M 定向留任方案，12 个月流失率下降 18%。"

## 8. 与 target_market 的交互

NA：DEI / employee experience / data-driven HR 是常见 framing；"people analytics" 是已成熟的 role family。
HK：跨境人才 / 区域 HRBP / 跨文化管理 经验显性；MNC 角色双语必备。
内地：组织变革 / 出海人力 / 国资 / 民企转型语境；"人力资源数据分析"或"组织效能"是常见标签；避免直接套用英文 "people analytics" 在没有生态语境的本地国企岗位。
