# Translation Glossary — CN→EN Canonical Mapping（中英简历术语词表）

> 简历英文版的术语翻译 canonical 来源。Pass 1.6 English Language Review 引用此表。
> 维护原则：每跑一份英文简历后，将新出现的术语 append 到对应分类。

---

## 0. 使用规则

1. **Canonical 列**是优先翻译选择；其他英文写法是可接受的备选
2. **不要直译**列出的中文短语在英文里直译会失礼或不通顺
3. 当 Canonical 列里同时给出多个选项（如"qualification framework / competency framework"），按对应中文场景选最贴近的
4. **JD-driven 例外**：如果 JD 用了某个英文术语，简历对齐 JD 用词（即使不是本表 canonical）

## 9. 维护规则

- **每跑一份英文简历**，将新发现的术语 append 到对应分类
- **冲突解决**：当同一中文有多个候选 canonical，按"国际化简历最常见"标准选；存疑时 grep `archive/legacy-root-resumes/*.tex` 看候选已用频次，多数即 canonical
- **入表门槛**：术语在 ≥2 份英文简历中出现 → 必须入表
- **过期 / 重复**：每季度梳理一次，删除重复条目，归并近义条
- **来源 cite**：每个 canonical 选择应可追溯到 (a) 已交付简历的实际用法，(b) 国际通用商业 / 咨询术语，或 (c) JD 原文
