# 差距弥补策略

当简历经历与JD不垂直时，在逐段优化之前先制定弥补策略。这一步是整个优化中最需要创造性思维的环节。

## 三层弥补策略

### 第一层：经历桥接（Reframe）

对每段看似不相关的经历，寻找"桥接角度"——用JD的语言重新解读已有经历。

**桥接思路：**
你做了 [原始经历] → 其中涉及的 [底层能力/方法] → 跟JD要求的 [目标能力] 是相通的

**桥接示例：**

| 原始经历 | JD要求 | 桥接角度 |
|---------|--------|---------|
| 咨询项目中做客户分级 | 用户运营的用户分层 | "客户分级"≈"用户分层"，强调分层逻辑和差异化策略 |
| 薪酬数据分析（美世） | AI+HR产品的业务场景理解 | 强调你理解HR的真实数据结构和业务痛点 |
| ML课程项目 | 药企临床数据分析 | 强调建模方法论和数据pipeline能力，弱化具体领域 |
| 咨询的recommendation deck | 产品策略的战略规划方案 | 同样是结构化分析→方案→决策支撑 |
| 活动策划经历 | 产品运营的活动运营 | 强调目标设定→执行→效果量化的闭环 |

**桥接可行性评估：**
对每段经历给出评级：
- **可桥接**：有合理的转换角度，改措辞就能对上
- **弱桥接**：勉强能连上但不自然，建议精简而非强行包装
- **不可桥接**：跟JD没有任何关联，建议精简到一行或删除

**桥接的底线：** 桥接是调整表述角度，不是编造。底层事实不能变，变的只是强调的维度和使用的术语。

### 第二层：经历补充建议（Add）

如果桥接后仍有JD核心要求无法覆盖，建议用户补充新经历。

**快速补充（1-2周内可完成）：**
- 做一个匹配JD方向的个人项目/Side Project
- 用现有技能做一个能展示目标能力的demo
- 参加一个相关的线上竞赛或hackathon
- 完成一个相关的在线课程并做出可展示的作业

**中期补充（1-3个月）：**
- 找一个相关方向的短期实习或volunteer项目
- 深入一个JD相关的开源项目并贡献代码
- 写一篇相关领域的分析文章/技术博客

**给建议时考虑：**
- 投递截止日期 → 近的只建议快速补充
- 用户技术栈 → 能覆盖的建议技术类项目
- 用户背景 → 偏商业的建议分析/研究类项目
- 补充经历的ROI → 一个项目能同时覆盖多个JD要求最好

### 第三层：技能栈调整（Skill Gap）

对照JD的技能要求，检查简历技能栏：

**情况1：你会但没写**
JD要求的技能你实际掌握但简历上没体现。
→ 直接加到技能栏
→ 必要时在经历中也体现（"运用XX工具完成..."）
→ 示例：JD要求Cursor/Copilot，你天天在用但简历没写

**情况2：你会一点但不精**
JD要求的技能你有基础但不够深。
→ 可以写在技能栏（不需要精通才能写）
→ 但避免在经历中过度强调
→ 示例：JD要求R Shiny，你用过R但没写过Shiny → 写"R"，面试前学Shiny

**情况3：你完全不会**
JD要求的技能你没有。
→ 坦诚告知用户这是一个gap
→ 如果可快速学习 → 建议学习路径和时间估算
→ 如果需要长期积累 → 建议评估是否值得投递

**技能栏排序原则：**
- JD提到的技能放第一行
- 按JD中出现的顺序排列（筛选者会按JD顺序扫描）
- 与JD无关的技能不删除但后移
