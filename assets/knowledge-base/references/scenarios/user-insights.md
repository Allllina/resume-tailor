# 用户洞察/用研方向简历优化标准

## 岗位画像

用户洞察（User Insights）/ 用户研究（UXR）岗位通过定性和定量研究方法深入理解用户需求、行为和痛点。常见于互联网公司、消费品公司和咨询公司的数字化部门。

## 核心能力评估维度

### 1. 研究方法论
- 关键词信号：深度访谈、焦点小组、可用性测试、问卷设计、Ethnography、Diary Study

### 2. 洞察提炼能力
- 关键词信号：用户画像（Persona）、用户旅程图（Journey Map）、需求图谱、洞察报告

### 3. 数据分析能力
- 关键词信号：SPSS/R/Python、统计分析、样本设计、显著性检验、回归分析

### 4. 业务影响力
- 关键词信号：推动产品迭代、影响战略方向、改变设计方案、支撑管理层决策

## Bullet写法：用研特定映射

[X] = 推动的产品决策或提升的体验指标，[Y] = 研究规模（样本量/覆盖面）或影响度量，[Z] = 具体研究方法和洞察产出。关键是体现完整链条：**研究问题 → 方法选择 → 执行规模 → 洞察产出 → 业务影响**

**优秀示例：**
- ✅ "主导新产品上线前用户研究，完成30场1v1深度访谈+2000份问卷调研，产出5类用户Persona和核心需求优先级矩阵，直接驱动产品MVP功能定义"
- ✅ "设计并执行可用性测试（N=20），发现支付流程3个关键体验障碍，推动UX团队重构交互方案，任务完成率从62%提升至89%"
- ✅ "搭建季度用户满意度追踪体系（NPS+CSAT），覆盖50万活跃用户，建立自动化预警机制，累计识别并推动修复12个高优体验问题"
- ✅ "运用Conjoint Analysis对5项定价方案进行用户偏好研究，样本量N=3000，为定价委员会提供数据支撑，最终方案上线后付费转化率提升18%"

**常见错误：**
- ❌ "进行了用户调研" → 什么方法？多少样本？产出了什么？
- ❌ "撰写调研报告" → 报告内容是什么？谁看了？产生了什么影响？

## 术语表

### 定性方法
深度访谈（IDI）、焦点小组（FGD）、可用性测试（Usability Testing）、卡片分类（Card Sorting）、情境访查（Contextual Inquiry）、日记研究（Diary Study）、民族志（Ethnography）

### 定量方法
问卷调研（Survey）、A/B测试、联合分析（Conjoint Analysis）、聚类分析（Cluster Analysis）、因子分析（Factor Analysis）、MaxDiff、NPS/CSAT

### 产出物
用户画像（Persona）、用户旅程图（Journey Map）、体验地图（Experience Map）、需求图谱、洞察报告、设计原则（Design Principles）、机会空间图（Opportunity Space）

### 工具
UserTesting、Maze、Hotjar、SurveyMonkey、问卷星、Qualtrics、SPSS、R、Dovetail、Miro

## 经历包装策略

**核心思路：** 证明你会做研究（方法论过硬），且研究真的有用（影响了决策）。每条 bullet 至少覆盖"方法→规模→洞察→影响"中的3个环节。
