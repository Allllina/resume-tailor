# 人力资本咨询 / 组织效能方向简历优化标准

## 岗位画像

人力资本咨询（Human Capital Consulting）/ 组织效能（Org Effectiveness）岗位以咨询视角解决组织、人才、薪酬、文化层面的业务问题。常见于 Mercer / Korn Ferry / Aon / WTW 的人力资本业务线、Big 4 的 People Advisory、企业内部 HR Strategy / Org Development 部门，以及国资 / 出海企业的海外子公司治理团队。

与 `people-analytics.md` 的区别：本方向更偏咨询、组织诊断与战略建议，分析方法服务于结构化判断；people-analytics 更偏数据建模与可重复 HR 数据产品。

## 核心能力评估维度

### 1. 组织诊断
简历信号：组织设计、span-of-control、岗位价值评估、组织效能评估、重组方案、海外子公司治理

### 2. 薪酬与人才市场
简历信号：薪酬 benchmarking、岗位评估（Hay/Mercer/IPE）、薪酬结构设计、长期激励、关键岗位市场扫描

### 3. 人才与领导力
简历信号：高潜识别、Succession Planning、Leadership Assessment、关键岗位继任、人才盘点、Talent Review

### 4. 跨文化 / 跨境人才管理
简历信号：海外子公司、外派管理、Localization、跨文化整合、Global Mobility、PMI 人力整合

### 5. 业务影响与高管沟通
简历信号：向 CHRO / 业务高管汇报、董事会人才报告、转型方案落地、变革管理

## Bullet 写法：方向特定示例

[X] = 推动的人才 / 组织决策或落地的方案，[Y] = 组织规模（FTE / BU 数 / 海外子公司数）/ 业务影响（流失率改善 / 成本节约 / 转型完成度），[Z] = 诊断方法 + 跨职能推动手段。

### 中文示例
- ✅ "主导某新能源车企海外 3 家子公司组织诊断，覆盖 1,200 FTE，结合 span-of-control 分析与 13 场高管访谈，识别出 4 类组织效能瓶颈并产出重组方案，CEO 采纳后年度运营成本下降 15%（约 8M）"
- ✅ "搭建集团级关键岗位继任体系，覆盖 3 个事业部 60+ 关键岗位，结合 9-Box 人才盘点与外部 benchmarking 完成 Succession Plan，向董事会人才委员会汇报，推动 12 名高潜进入 18 个月专项培养"
- ✅ "完成 5 个职能 80 个岗位的薪酬体系重设计，基于 Mercer IPE 岗位评估与外部薪酬调研定位市场分位，重塑薪酬带宽与长激方案，推动核心岗位流失率从 18% 降至 9%"
- ✅ "诊断海外子公司 PMI 后人力整合风险，识别出文化冲突与汇报线模糊两大核心问题，产出 30/60/90 天整合 roadmap，向集团 CHRO 汇报后纳入正式整合 KPI"

### 英文示例
- ✅ "Led organization design diagnostic across 3 overseas subsidiaries (1,200 FTE) for a mid-cap auto OEM, combining span-of-control analysis with 13 executive interviews to identify 4 effectiveness bottlenecks; restructuring recommendation adopted by CEO, reducing annual operating cost by 15% (~$8M)"
- ✅ "Designed succession framework for 60+ critical roles across 3 business units, integrating 9-Box talent review with external benchmarking; reported to board talent committee and placed 12 high-potentials into an 18-month accelerated development program"

### 常见错误
- ❌ "负责员工关系管理" → 太泛，缺商业影响
- ❌ "参与组织诊断项目" → 你的具体诊断方法、scope、产出是什么？
- ❌ 列了一堆 HR 模块（招聘 / 培训 / 绩效）但没说改善了什么 → HR 行政岗，不是 HC 咨询
- ❌ 用"赋能 / 抓手 / 闭环"等空泛词 → 见 `quality-pass.md` Pass 2 AI 味清洗

## 经历包装策略

### 核心思路
"组织诊断者 + 数据可证据化 + 高管影响力" 三位一体。本方向必须证明：①你能用结构化方法诊断组织 / 人才问题，②有数据支撑（不是凭感觉），③你的诊断推动了 CHRO / 业务高管的真实决策。

### Mercer / Desay SV 经历的核心钩子（按 `resume-rewrite-engine/README.md` strategic positioning rules）
- **Mercer 经历** — 直接对应：薪酬 benchmarking / 岗位评估 / 组织效能。bullet 必须显化客户行业、scope（FTE / 岗位数 / BU 数）、产出物（重设计方案 / 数据库 / 报告）和客户决策影响
- **Desay SV 经历** — 海外子公司治理、跨文化人才整合、组织绩效。bullet 必须显化海外子公司数 / 区域、组织规模、识别出的具体问题与方案

### 非 HC 经历的桥接表

| 原始经历 | HC 方向表述 |
|---|---|
| 咨询（如 Kearney 战略项目） | 强调结构化诊断方法 + stakeholder 沟通 + 客户决策影响（保留咨询硬实力，叠加组织 / 人才语境）|
| 用户调研（如 Ipsos） | 调研方法论可迁移到 employee survey / engagement / pulse；强调样本设计、定性 + 定量结合、洞察→决策 |
| 数据分析 | 弱化纯数据 / 模型，强调用数据回答组织 / 人才业务问题（人效、流失驱动、薪酬公平性）|
| 业务运营 | 强调跨部门协作、变革管理、向高管汇报 |

### 加分项
- 有海外 / 跨境项目经验（用户的 Desay SV 海外子公司是核心 hard-sell）
- 有客户行业 expertise（汽车 / 消费 / 互联网 / 国资 / 制造）
- 有量化的薪酬或组织诊断方案（具体到岗位数 / FTE / 节约金额）
- 直接面对 CHRO / 业务一把手汇报的经历
